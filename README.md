# Survival Game - Space Shooter

A 2D space shooter built with Python and Pygame.

This is my Python game project, created to learn the fundamentals of Python programming, game development, object-oriented programming, and Git/GitHub.

## Features

- Player movement with keyboard controls
- Continuous shooting with weapon cooldown
- Enemy spawning and movement
- Bullet/enemy collision detection
- Player health system
- Score tracking
- Progressive difficulty
- Level system
- Animated procedural starfield
- Particle explosion effects
- Laser and explosion sound effects
- Start menu
- Game-over and restart system

## Controls

- **Left Arrow** — Move left
- **Right Arrow** — Move right
- **Space** — Fire
- **Enter** — Start game
- **R** — Restart after game over

## Built With

- Python
- Pygame
